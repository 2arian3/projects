  1. 01Columns are rowsScoped to a project, team, or person.

Lambda has one knob: memory. It also sets CPU. You pay memory times duration, so cost curves bend. ML adds a second knob: which model to serve. OptiServe picks both, per step, under constraints. Search strategies come from published research. The engineering is mine.
OptiServe · System design

Measure live. Optimize offline.

  1. 01ProfileSweep memory sizes on a live Lambda.
  2. 02ModelFit latency curves. Collapse loops and branches.
  3. 03OptimizeGreedy search along the critical path.

137 of 155 tests need no AWS.

Left half costs money and is noisy. Right half is free and deterministic. They meet at one method. Curves become a table. Why greedy: sub-second, and the gap is measured. Bug stories if asked: prep guide, Story 1.

Realest · System design

One store, written by voice, read by the page.

  1. 01Schema at the boundaryModel output enters only as typed fields.
  2. 02Rank on writeA pure function reorders the page instantly.
  3. 03Polling over socketsA dropped poll recovers on the next tick.

Voice writes the store. The page only reads. Every model output crosses a typed schema. Ranking is pure, so speech never waits. If asked about scale: the fan-out needs a queue.
